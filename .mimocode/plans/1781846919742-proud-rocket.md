# 智谱AI 去除图片水印

## 背景
智谱AI (CogView) 生成的图片默认带有"AI生成"水印。API 支持 `watermark_enabled: false` 参数去除水印。

## 前提条件
用户需要先在智谱AI平台签署免责声明：
**个人中心 → 安全管理 → 去水印管理**

签署后 `watermark_enabled: false` 才会生效。

## 修改方案

### 文件：`src/worker/services/ai.ts` - `generateImage()` 函数

在图片生成请求的 body 中添加 `watermark_enabled: false`：

```ts
const body: any = {
  model: imageModel,
  prompt,
  size: imageSize,
  watermark_enabled: false,  // 添加此行
  extra_body: { response_format: "url" },
};
```

## 验证
1. 在智谱AI平台签署去水印免责声明
2. 重新生成图片，确认无"AI生成"水印
