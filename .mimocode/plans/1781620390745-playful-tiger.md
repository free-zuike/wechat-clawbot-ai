# 修复：图片/视频生成支持非 Cloudflare 提供商

## 问题
当前 `generateImage` 和 `generateVideo` 硬编码调用 `aiBinding.run()`（Cloudflare Workers AI binding），对 Agnes AI 等 OpenAI 兼容提供商无效。

用户的 Agnes AI 模型：
- 文本：`agnes-2.0-flash`
- 图片：`agnes-image-2.1-flas`
- 视频：`agnes-video-v2.0`

## 方案
图片/视频生成也需要走 OpenAI 兼容 API（`callOpenAICompatible` 模式），当 provider 不是 cloudflare 时，用 HTTP fetch 调用。

### 修改文件
- `src/worker/services/ai.ts` — `generateImage` 和 `generateVideo` 增加非 Cloudflare 分支，用 fetch 调用 OpenAI 兼容接口
- `src/worker/services/ilink-do.ts` — 传递 provider/baseUrl/apiKey 给生成函数

### 关键改动
1. `generateImage` 签名增加 `baseUrl` 和 `apiKey` 参数，非 cloudflare 时用 fetch 调用图片生成 API
2. `generateVideo` 同理
3. 调用方传递完整的 provider 配置

### 验证
- 在管理后台配置 Agnes AI 提供商 + 正确模型名
- 发送"画一只猫" → 应调用 Agnes AI 图片 API
- 发送"生成视频" → 应调用 Agnes AI 视频 API
